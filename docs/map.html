How sure the model is, race by race

Each race is shaded by the model's confidence in its pick: dark when the favorite is near-certain, light when it's a lean, gold when it's a tossup. Gray races are on the ballot but have no public polls, so the model doesn't project them. Hover or tap a race for the numbers.

How to read it

  • Confidence is the model's win probability for its favorite: Safe 95%+, Likely 80-95%, Lean 60-80%, Tossup under 60%. These are the same tiers as the forecast page, where every race has an explainer.
  • No projection means the race is on the ballot but has no public polls, which the model needs. Most House districts are in that group.
  • House: each square is one district, inside its state's tile. Squares run from the most Democratic projection to the most Republican, then the unprojected ones, so a square's place isn't the district's location. Tiles sit in a fixed grid, not on a true map, so every state stays visible and every district gets the same space.
  • Fragile races are ones where the pick flips if every poll is off by 3 points in one direction, which has happened in past cycles.
  • The numbers update with every model run. The states' shapes come from the Census Bureau's cartographic boundaries (via us-atlas).
